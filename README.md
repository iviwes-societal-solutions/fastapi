# FastAPI Authentication System

## Connects to a database and can make authentication

### How to get
1. clone this repository (git clone https://github.com/iviwes-societal-solutions/fastapi.git)
2. install requirements (pip install -r requirements.txt)
3. create a file called .env and add DB_URL='${your_database_url}'
4. run server (python -m uvicorn --reload app.main:app)
5. start making requests
